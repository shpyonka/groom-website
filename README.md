# https://groom.website
Веб-сайт для проекта GROOM. 

Учебный проект по созданию полнофункционального, адаптивного сайта для студии груминга домашних животных.

**🚀 О проекте:** этот сайт был создан в рамках обучения современной фронтенд-разработке для отработки практических навыков. Он представляет собой виртуальную студию груминга с полным набором страниц: Главная, Услуги, Команда, Галерея, Контакты и Юридические Документы.

**Ключевые особенности:**
* Полностью адаптивный дизайн, корректно отображается на мобильных устройствах и планшетах.
* Интерактивные элементы: "переворачивающиеся" карточки на главной странице, форма онлайн-записи.
* Клиентская маршрутизация (SPA) без перезагрузки страниц.
* Проработанные страницы с политикой конфиденциальности и публичной офертой.

**🛠️ Используемые технологии:**

**Frontend:** React 18, React Router DOM 6

**Сборка:** Vite

**Стили:** Pure CSS (использованы Flexbox, Grid, CSS-анимации)

**Хостинг и домен:** Beget.com 

**Инструменты:** Git, GitHub

**Sitio web para el proyecto GROOM.**
Proyecto de formación para crear un sitio web totalmente funcional y adaptable para un salón de peluquería canina.

Se trata de un salón de peluquería virtual con un conjunto completo de páginas: Página De Inicio, Servicios, Equipo, Galería, Contacto y Documentos Legales.

* Elementos interactivos: tarjetas desplegables en la página de inicio, formulario de reserva online.
* Navegación de clientes (SPA) sin recargas de página.
* Páginas bien diseñadas con política de privacidad y oferta pública.
